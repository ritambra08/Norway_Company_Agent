# Signalpost site built with JBOX

The JBOX bonus asks for a simple site where someone can find a company, compare two, and check where a fact came from, on laptop and phone.

- **Brief:** [jbox/SIGNALPOST_JBOX_BRIEF.md](jbox/SIGNALPOST_JBOX_BRIEF.md). Paste it as the first JBOX message.
- **Attachments:** [jbox/DATA_SPEC.md](jbox/DATA_SPEC.md), a few lines of `submission/profiles.jsonl` as a sample, and screenshots of `submission/index.html` as layout references.
- **Data:** the site fetches `https://raw.githubusercontent.com/ritambra08/Norway_Company_Agent/main/submission/profiles.jsonl` server-side, hourly. It needs no database, login or keys.
- **Updating:** run `make smoke`, then commit and push `submission/`. The site picks up the new data within an hour.
- **Fallback viewer:** `submission/index.html` (or `out/index.html` after any run) is the offline viewer generated by the agent itself.
